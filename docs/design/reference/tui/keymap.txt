EXOCOMP TUI — KEYBINDING SPEC · v0.2 · 2026-08-22
source: exocomp - TUI.dc.html (T13 · T14 · T15)
constraints: no F-keys, no Alt-combos, nothing tmux eats.
one meaning per letter across the whole app — a letter never changes
meaning between screens.

GLOBAL — WORK EVERYWHERE
  0-6           jump to screen
  tab / S-tab   next / previous screen
  j k · ↓ ↑     move selection
  g / G         top / bottom
  enter         open selected thing
  esc           close / back — never quits
  /             filter current table
  p             pause reactive (one keystroke from anywhere)
  m             mute notifications (modal, expiry required)
  ?             help overlay — full map
  q             quit to shell (root level only)

PER SCREEN
  [0] home        enter opens the selected needs-you item
  [1] jobs        enter tail · f follow · c cancel (confirms)
  [2] backups     b run now · enter last runs
  [3] workspaces  enter detail · l plan now
  [4] schedules   space enable/disable · x run now
  [5] approvals   a approve* · r reject · d diff pager
  [6] events      e trace · o filter outcome

  * on a destroy-carrying plan, a opens the typed-confirmation modal
    (workspace name) — never a bare approve.

RESERVED LETTERS — NEVER REASSIGNED
  a r d   approve / reject / diff (approvals only)
  e       explain (trace)
  b       run backup
  f       follow
  c       cancel
  x       execute
  o       outcome filter
  l       plan
  space   toggle
